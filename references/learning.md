# Learning mode

Use when the user needs retention, reconstruction, or transfer rather than an explanation alone. Do not turn every explanation into a curriculum.

## Select the smallest sufficient test

- **Reconstruct**: explain the idea without copying the source.
- **Boundary**: give a counterexample or state where the idea stops applying.
- **Transfer**: use it on a structurally similar but superficially different problem.
- **Prediction**: make an observable prediction before seeing the answer.
- **No-AI recall**: use when the user claims mastery or needs durable retention.
- **Visible use**: request an artifact only when application is part of the learning goal.

Failure on a test identifies the next learning target; it does not justify a global judgment about the learner.

## Output

State what is understood, what remains uncertain, and one suitable reconstruction, boundary, transfer, or recall check. Mark material as “encountered” rather than “mastered” when no independent performance has been observed.
