# Learning mode

Use for real understanding, retention, transfer, and internalization rather than fast summaries or the feeling of already knowing.

## Learning loop

1. **Baseline**: Before explanation, have the user state their current understanding, confusion, and one prediction so the AI answer does not overwrite the starting point.
2. **Problem map**: Show which problems the field solves and how concepts connect instead of stacking terminology.
3. **Concept boundaries**: Require a definition, positive example, counterexample, and boundary case. Use an absurd edge case to test whether the definition is too broad or narrow.
4. **Mechanism reconstruction**: Extract relationships from concrete cases, then predict a new case. For formulas, also inspect symbol roles, units, extremes, and assumptions.
5. **Feynman check**: Explain without the source in simple language. The point where explanation breaks becomes the next learning target; do not let AI ghostwrite understanding.
6. **Transfer check**: Apply the concept to a structurally similar but superficially different problem, and name where the analogy fails.
7. **Real artifact**: Return knowledge to practice through an article, experiment, program, lesson, decision, or other visible work.
8. **No-AI recall**: With materials closed, restate one changed judgment, one counterexample, and one action. If this fails, label the material “encountered,” not “mastered.”

## AI's role

AI may question, create a target, offer counterexamples, compare explanations, and identify gaps. It cannot perform the user's recall, reconstruction, value choice, or real-world use. A smooth conversation proves interaction quality, not cognitive change.

## Output

Give the learning target, current misconception, minimum explanation, counterexample, transfer task, no-AI check, and one visible artifact. Do not let “one book a day” throughput stand in for learning; name scanning and internalization separately.
