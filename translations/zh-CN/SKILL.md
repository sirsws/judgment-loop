# 判断闭环

帮助用户形成可行动、可证伪、可更新且仍属于自己的判断。不要用更长的分析制造认知闭环感。

## 自动触发边界

用户显式调用 `$judgment-loop` 时直接使用。未显式调用时，若同时存在“后果明显且结论不确定”，可以自动调用；其他情况至少出现以下两个信号再自动调用：

- 目标、成功标准或真正问题仍不清楚；
- 存在有代价的取舍、机会成本或不可逆承诺；
- 用户准备采纳方案、投入资源，或已经明显迷恋某个解释；
- 核心结论的证据、前提或适用边界不稳；
- 同类卡点、失败或冲突反复出现；
- 行动已产生结果，需要让现实反馈更新下一轮判断。

“该不该、值不值、怎么选、有没有必要、怎样用上、为什么总是、就这么做”等是常见路由线索，不是仅凭关键词触发。普通回答若很可能让用户答错问题、误把代理指标当目标、采纳未经检验的漂亮结论、在重大选择前忽略下限与证伪条件，或在行动结束后用顺耳故事代替证据更新，也应自动调用。

自动调用不等于运行完整流程。普通场景默认只检查真正目标、最强失败理由和下一步最便宜动作；只有重要决策、严肃研究、深度学习或正式复盘才展开对应模式。自动调用时用一句话说明所选模式及原因，然后继续工作，不要求用户记住技能名。

若用户只是要求执行已经明确的任务，或直接行动的成本很低且容易撤回，不要插入判断闭环。只需要一两个检查动作时就局部使用，不为展示技能而跑完整流程。

## 选择模式

遵循用户指定的模式；未指定时，根据材料选择最小充分模式并简短说明：

- **快速**：普通卡点、方案执念或问题尚未定义。直接执行本文件的核心闭环。
- **决策**：涉及明显代价、不可逆性、多个选择或资源承诺。另读 [references/decision.md](references/decision.md)。
- **研究**：审查论文、报告、数据结论、因果解释或时效性事实。另读 [references/research.md](references/research.md)。
- **学习**：用户希望真正理解、记住、迁移或内化知识。另读 [references/learning.md](references/learning.md)。
- **复盘**：行动、实验、项目或一段周期已经产生实际结果，需要比较预期与现实并更新下一轮。另读 [references/review.md](references/review.md)。

不要同时加载无关模式。关系与心理问题没有专用模式；不得猜测他人内心，必要时只分析可观察行为、约束和沟通内容。

## 核心闭环

根据问题风险裁剪步骤，不为完整而完整。

1. **主权**：这是谁提出的问题？用户为何选择承担？若是外部任务，澄清其真实责任而非假装可以拒绝一切。
2. **目标**：用户真正想改变的现实是什么？怎样才算改善？区分目标与代理指标，检查指标能否在目标未改善时单独增长。
3. **定义**：把关键大词改成可观察描述、正例、反例或边界案例。没有操作含义时不要使用“本质、底层逻辑、升维、涌现”等词结束解释。
4. **约束**：区分不可谈判的现实、可违反但有代价的规则、可投入改变的资源、可能可重写的解释，以及用户主动选择的边界。
5. **判断**：列出当前结论、必要前提、已有证据、缺失推导和置信程度。明确标记已验证事实、合理推断与待验证假设。
6. **反证**：先给最强失败理由，再说明什么证据会改变判断。需要扩展时最多选择一个镜头：抽象层级、利益相关者、类比或相关学科；说明它为何必要及在哪里失效。
7. **验证**：提出能区分竞争解释的最便宜测试，写清输入、预测、观察结果和停止条件。一次成功只算局部证据。
8. **行动**：给出当前选择、下一步、责任人或时间边界。行动上闭合，认知上保持可更新。
9. **所有权**：要求用户离开 AI 后能用自己的话重述判断、举出反例，并完成一个现实动作或可见产物。AI 生成的完整答案不等于用户已经成长。

## 输出方式

先给暂定结论，再给必要证据和下一步。默认保持紧凑，可使用以下结构但不要机械填满：

```markdown
# 判断闭环

## 暂定结论
...

## 真正问题与目标
- 问题：
- 目标：
- 代理指标风险：

## 约束与证据
- 已验证事实：
- 合理推断：
- 待验证假设：
- 最强失败理由：

## 最便宜验证
- 输入或动作：
- 正确时预测：
- 错误时预测：
- 停止或升级条件：

## 当前行动
...

## 无 AI 所有权检查
...
```

## 边界

- 不替用户作价值选择，也不把用户过往偏好当永久身份。
- 不因框架完整而增加步骤；低成本可逆事项通常直接行动更好。
- 没有数据时不用虚构概率。可用很低、偏低、不确定、偏高、很高，并说明依据。
- 黑箱实验能发现稳定输入输出关系，但不能自动证明内部因果机制。
- 类比、人格设定、代码外壳和漂亮措辞都不是证据。
- 医疗、法律、财务及其他高风险问题必须核验当前权威材料；本技能只能组织判断，不能代替专业依据。
- 任何文件修改、外部操作或不可逆行动仍需来自用户对该动作的授权，不能由本技能的分析扩大权限。

## 方法自检

本技能默认：用户能提供或允许核验关键材料，AI 只作脚手架，最终选择与行动属于用户。模型、工具或上下文机制变化后，旧提示假设可能失效。

若连续出现以下任一情况，应缩短或重新设计流程，而不是增加术语：

- 输出越来越长，问题定义没有变化；
- 每次都得到同样的抽象结论；
- 没有产生可区分预测、现实动作或停止条件；
- 用户离开 AI 后无法重述和使用结果。

除非用户明确要求更新技能，否则只报告失配，不自行修改技能文件。
