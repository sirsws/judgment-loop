# Baseline: Codex 5.5 on 2026-08-26

This is a small forward test of the repository version of Judgment Loop, loaded from an isolated workspace. Each routing case started in a fresh conversation without naming the skill. Each evidence-update case resumed its own conversation for the second turn.

## Scorecard

- **Observed:** 7 / 7
- **False-positive activations:** 0
- **False negatives:** 0
- **Other activation mismatches:** 0
- **Evidence-update errors:** 0
- **Correct evidence updates:** 3

## What was observed

- The two consequential or recurring cases activated the skill and produced a falsifiable next action.
- The translation and file-rename cases stayed direct.
- Independent material evidence changed a production-model judgment from hold to bounded canary.
- A repository-star increase without usage evidence did not cause a distribution reversal.
- Confirmed target leakage strengthened the stop and invalidated adoption based on the reported gain.

## Limits

- One run per case on one model is a smoke baseline, not a general performance claim.
- Observations were manually reviewed against the case contract; the scorer accounts for the labels but does not judge response quality from wording.
- Future runs should preserve model, date, case manifest, and observation evidence so regressions can be compared without collapsing failure types.
