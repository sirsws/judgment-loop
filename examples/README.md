# Examples

These examples show the behavioral difference the skill should create. They are not fixed output templates.

## 1. Publishing a project

**Input**

> The work feels useful. Should I publish it to every marketplace now?

**Without the loop**

The answer may optimize platform coverage: package it, write a README, and publish everywhere.

**With the loop**

- Real target: obtain credible external-use evidence, not merely occupy platforms.
- Proxy risk: listings, stars, and downloads can rise without the skill improving anyone's judgment.
- Strongest failure: strangers may see only another “think deeply” prompt.
- Cheapest test: fresh install plus positive, negative, and boundary trigger cases.
- Action: one canonical repository, then distribution layers after the install contract passes.

## 2. Adopting a research result

**Input**

> This paper reports a 12% improvement. Should we integrate the method?

**With the loop**

- Verify the primary paper and identify the baseline.
- Separate knowledge increment from engineering packaging.
- Look first for leakage, selection bias, proxy metrics, and unfair comparison.
- Run the cheapest same-sample test that separates the claimed mechanism from an alternative explanation.
- Do not modify production until the evidence crosses a stated gate.

## 3. Learning with AI

**Input**

> I had a very deep conversation about Bayesian reasoning. Have I learned it?

**With the loop**

- Close the chat and reconstruct the idea without notes.
- Give a counterexample and a boundary case.
- Apply it to a superficially different problem.
- Produce one decision or visible artifact.
- If those fail, label it “encountered,” not “mastered.”

## 4. When not to use the skill

**Input**

> Rename `draft.md` to `final.md`.

The task is clear, cheap, reversible, and low risk. Perform it directly. Do not add a judgment ceremony.
